# Happy Birth Day

世界のどこかに生まれ、1歳ずつ歳を重ねていく人生シミュレーションゲームです（1プレイ30分前後）。
`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。進み具合はブラウザに自動保存されます。

## 遊び方

1. **🎂 生まれる** … 36か国から、世界の出生数の割合で生まれる国が決まります。性別・階級（⭐1〜5）・親の仕事や年収・家の貯金もランダム
2. **毎年3つの選択** … 🎯行動（ステータスを育てる）／🧬性格のタネ／🎨趣味の時間
3. **❗大事な選択** … 幼稚園〜大学院の受験、就職、病気の治療、スカウト、プロポーズ、留学、引退など
4. **🧭 人生の選択** … クラブ・部活、趣味、仕事探し・転職・パート、恋愛・結婚・離婚、ペット、マイホームはいつでもこのタブから
5. **🎂 次の誕生日へ** … 1年が経ち、毎年1〜5個の思い出がログに流れます
6. **エンディング** … プロフィール・家族・人生のハイライト・人生をひとことで表す言葉。📸ボタンで画像として保存

## ファイル構成

```
index.html             画面
css/style.css          デザイン（ライト／ダーク対応）
js/data/countries.js   国データ（出生数・生活水準・進学補正・平均寿命・初婚年齢・名前・食べ物・お祭り・死因）
js/data/content.js     ステータス・性格・行動・趣味・学校・学部・仕事・ペット・家・病気
js/data/events.js      毎年の思い出（年齢・学校・仕事・家族・趣味・性格・国によって変わる）
js/game.js             ゲームの進行と計算
js/ui.js               画面の描画と操作
```

## 仕様メモ（解釈したところ）

- 金額は日本の金額を基準に、住んでいる国の生活水準を掛けています。給料は「月給」、学費やペット代は「年額」です。
- 死亡率は国の平均寿命・乳児死亡率から作った年齢別モデル。健康なときは-20%、病気を放置するたびにこのボーナスが2%ずつ減ります。
- 0〜4歳の死亡率は国ごとの乳児死亡率・5歳未満死亡率から作っています。1〜4歳は幼いほど重く配分（1歳40%・2歳25%・3歳20%・4歳15%）し、健康ボーナスがかかっても実際の5歳未満死亡率と同じくらいになるよう×1.2しています。
- 結婚中の離婚は「毎年10%」だとほとんどの夫婦が別れてしまうため、結婚3年目以降に毎年6%で起きる「夫婦の危機」のときに、仕様の離婚率（10%＋相反する性格×10%など）で判定しています。恋人は仕様どおり毎年判定します。
- ピアニストは吹奏楽6pt、声楽家は合唱6ptが条件。
- 進学の知性ボーナス＝（知性−学校ごとの基準値）×0.4（-10〜+20%）。基準値は小学校20／中学校35／高校45／大学55／大学院60。
- 進学の国の補正（その国の進学率による合格率の減少）は、下限0.6倍です。
- 病気になる確率＝（100−基本値）×0.35×年齢の補正。基本値＝（健康×2＋体力）÷2.5（5〜95）、年齢の補正は0〜5歳×1.3／6〜49歳×1.0／50〜64歳×1.3／65〜74歳×1.6／75歳〜×2.0。
- 性格のタネは、その年齢で芽生える性格の中からランダムで出ます（どの性格が育つかは表示しません）。必要ポイントを超えても貯まり続けます。
- 毎年の行動は6つ：①いちばん低いステータス（最安）②いちばん低いステータス（ほか）③100未満でいちばん高いステータス（最安）④2番目に低いステータス ⑤⑥ランダム。
- プロポーズ成功率＝80%－（平均初婚年齢との差）×3%（下限25%）＋交際1年ごとに5%（最大+20%）。離婚・死別後10年間は基本40%。
- 適齢期（平均初婚年齢の-8〜+12歳）には、出会い（付き合う／付き合わない）やプロポーズ（する／される）のカードが自動で出ます。人生の選択タブのボタンも引き続き使えます。
- 結婚すると、60歳まで3年ごとに「子どものこと」カード（そろそろ考える／まだいい／養子を迎える）が出ます。自然に子どもが生まれるのは「考える」を選んでいるあいだだけ（1年あたり約60%、30歳以下なら最初の子は3年以内に約9割）。出身国の平均の子ども数が2人を超える国では、妊娠確率に＋（平均−2）×15%のボーナスがつき、平均の人数までは生まれにくくなりません。養子は同じ国か近隣の（先進国以外の）国の0〜11歳の子です。結婚していなくても、18歳以上で学生ではなく仕事についていれば、人生の選択タブから養子を迎えられます（1年に1人まで）。
- 子ども（養子も）の小学校・中学校・高校・大学への進学と就職は、親としてカードで選びます。大学の学部はランダムで、法学部・医学部・薬学部を卒業した子は大学院に進むか働くかを選べます。就職先の候補は子どもの学歴（中卒以下／高卒／大学の学部）で選べる仕事だけが出ます。子どもの恋愛や結婚は本人が決めます。
- 趣味が3つ未満のときは10年に1度くらい「新しい趣味のお誘い」、ペットがいないときは10年に1度くらい「ペットとの出会い」のカードが出ます。
