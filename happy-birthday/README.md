# Happy Birth Day

世界のどこかに生まれ、1歳ずつ歳を重ねていく人生シミュレーションゲームです（1プレイ30分前後）。
`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。進み具合はブラウザに自動保存されます。

## 遊び方

1. **🎂 生まれる** … 36か国から、世界の出生数の割合で生まれる国が決まります。性別・階級（⭐1〜5）・親の仕事や年収・家の貯金もランダム
2. **毎年3つの選択** … 🎯行動（ステータスを育てる）／🧬性格のタネ／🎨趣味の時間
3. **❗大事な選択** … 幼稚園〜大学院の受験、就職、病気の治療、スカウト、プロポーズ、留学、引退など
4. **🧭 人生の選択** … クラブ・部活、趣味、仕事探し・転職・パート、恋愛・結婚・離婚、ペット、マイホームはいつでもこのタブから
5. **🎂 次の誕生日へ** … 1年が経ち、毎年1〜5個の思い出がログに流れます
6. **エンディング** … プロフィール・家族・人生のハイライト・人生をひとことで表す言葉。📸ボタンで画像として保存

## ファイル構成

```
index.html             画面
css/style.css          デザイン（ライト／ダーク対応）
js/data/countries.js   国データ（出生数・生活水準・進学補正・平均寿命・初婚年齢・名前・食べ物・お祭り・死因）
js/data/content.js     ステータス・性格・行動・趣味・学校・学部・仕事・ペット・家・病気
js/data/events.js      毎年の思い出（年齢・学校・仕事・家族・趣味・性格・国によって変わる）
js/game.js             ゲームの進行と計算
js/ui.js               画面の描画と操作
```

## 仕様メモ（解釈したところ）

- 金額は日本の金額を基準に、住んでいる国の生活水準を掛けています。給料は「月給」、学費やペット代は「年額」です。
- 死亡率は国の平均寿命・乳児死亡率から作った年齢別モデル。健康なときは-20%、病気を放置するたびにこのボーナスが2%ずつ減ります。
- 結婚中の離婚は「毎年10%」だとほとんどの夫婦が別れてしまうため、およそ4年に1度の「夫婦の危機」が起きたときに、仕様の離婚率（10%＋相反する性格×10%など）で判定しています。恋人は仕様どおり毎年判定します。
- ピアニストは合唱6pt、声楽家は吹奏楽6ptが条件（仕様の記載どおり）。
- 子どもは結婚後に国の出生率をもとに自然に生まれます（「子どもを望まない」も選べます）。
