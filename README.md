# すべて億分の1

81億人の誰かとして、もう一度生まれてみる。
世界のどこかに生まれ、一年ずつ人生を歩むブラウザ人生シミュレーションゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・サーバー不要）。

1. **🎲 生まれる** … 人口に比例した確率で、23か国のどこかに生まれます（国・性別・名前を選ぶこともできます）
2. **🎂 次の年へ** … 1年が経ち、出来事や思い出が流れてきます
3. **🎯 行動** … 1年に3回、好きな行動でパラメーターを育てます
4. 人生の終わりには、ハイライトや人生スコアがまとめて表示されます

進み具合はブラウザ（localStorage）に自動保存されます。

## 主な特徴

| 要望 | 実装 |
| --- | --- |
| 本人と家族の基本情報をすぐ見られる | 画面上部のプロフィールに、名前・年齢・職業・貯金・年収と家族の一覧が常に表示。家族をタップすると名前・続柄・年齢・職業・年収・結婚歴・子どもの有無・性格・仲の良さまで確認できる。「👪 家族」タブで全員の詳細も一覧できる |
| パラメーターを増やし、上げる手段も増やす | 健康・幸福・心の余裕・知性・外見・体力・社交性・感性の8種類。からだ／こころ／まなび／みため／しゅみ／ひと の6カテゴリ、30種類以上の行動で育てられる |
| 選択に必要な情報を出す | 結婚・お見合い・恋人探しでは相手の名前・年齢・職業・年収・過去の結婚歴・子どもの有無・性格・相性を表示。家・進学・投資・介護など、お金がかかる選択では貯金・年収・世帯年収・費用を「📋 判断材料」に表示 |
| その国ならではの文化イベント | 23か国それぞれのお祭り（ディワリ、春節、カーニバル、死者の日、ソンクラーン…）と、成人式・高考・修能・兵役・キンセアニェーラ・ダーチャの夏などの国別イベント |
| 見やすいUI | パステル調のカードUI、スマホ／PC両対応、ダークモード対応。ログは種類ごとに色分け（節目・文化・思い出・行動・性格） |
| 個性豊かな思い出 | 年代別・性格別・国別の思い出テンプレートに、家族やペット、友達の名前、その国の食べ物や名所が入る |
| 選択で性格が育つ | 選択肢や行動ごとに性格の「芽」が育ち、一定以上で新しい性格が芽生える。正反対の性格（例：慎重派↔冒険好き）は入れ替わる。性格は毎年のパラメーターや思い出にも影響する |

## ファイル構成

```
index.html               画面
css/style.css            デザイン
js/game.js               ゲームの進行・計算
js/ui.js                 画面の描画・操作
js/data/countries.js     国データ（名前・通貨・食べ物・名所・お祭り）
js/data/country_events.js 国ごとの文化イベント
js/data/events.js        世界共通のイベント・動的イベント
js/data/activities.js    行動
js/data/jobs.js          仕事
js/data/traits.js        性格
js/data/memories.js      思い出のテンプレート
```

イベントや思い出はデータファイルに追加するだけで増やせます（書き方は各ファイル冒頭のコメント参照）。
